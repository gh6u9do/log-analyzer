# log-analyzer

Скрипт на Python (pandas) для разбора логов веб-приложения и поиска проблем в них: статистика по уровням логирования, доля ошибок, топ повторяющихся ошибок, нагрузка в минуту и распределение HTTP-статусов.

Поддерживаемые форматы — **JSONL** и **TSKV**: именно такие логгеры реализованы в приложении [Film React Nest](https://github.com/gh6u9do/film-react-nest) (NestJS, MongoDB, Docker), формат выбирается через переменные окружения. Папка `sample_logs/` содержит демонстрационные данные в этих форматах.

## Запуск

```bash
pip install pandas

python analyze_logs.py sample_logs/app.jsonl
python analyze_logs.py sample_logs/app.tskv --format tskv
```

## Зачем это нужно

Типовая задача аналитика/разработчика — «разобрать данные»: понять, где слабые места системы, какие ошибки повторяются и что стоит чинить в первую очередь. Скрипт отвечает на эти вопросы по логу за один запуск.

## Что используется из pandas

- `pd.DataFrame` — табличное представление лога;
- `value_counts()` — подсчёт записей по категориям (уровни, статусы);
- булева индексация `df[df['level'].isin([...])]` — фильтрация ошибок;
- `pd.to_datetime()` и `resample('1min')` — агрегация по времени;
- `sort_index()`, `head()` — топ повторяющихся ошибок.
